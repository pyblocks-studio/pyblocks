# PyBlocks

PyBlocks Studio is a visual, block-based coding environment designed to make learning and building Python effortless. Drag, drop, and snap blocks together to generate clean Python code in real time!

---

## Features

* **Visual Drag-and-Drop Workspace:** Snap blocks together intuitively using organized drawers (Output, Variables, Logic).
* **Live Python Translation:** Watch visual blocks turn into clean, executable Python scripts side-by-side on the fly.
* **Instant Execution:** Run and test your Python logic right inside your browser console.
* **Export Ready:** Download clean, production-ready `.py` files with a single click.

---

## Quick Start

1. Open `index.html` in any web browser.
2. Drag blocks from the **Palette** into the **Workspace**.
3. Inspect your live code in the **Translated Python Code** panel.
4. Click **Run Python** or **Export Code**!
