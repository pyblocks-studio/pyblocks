# PyBlocks Studio Repository Audit

Audit date: 2026-08-01
Audited baseline: local `main` commit `e61d4b8`
Working branch: `audit/repository-hardening`

## Scope and method

Every first-party HTML, CSS, and JavaScript file was manually inspected:

- `index.html`, `editor.html`, `license.html`
- `css/home.css`, `css/main.css`, `css/settings.css`
- `js/blocks.js`, `js/main.js`, `js/python-engine.js`, `js/theme-settings.js`

Vendored/minified Blockly files were inventoried but excluded from refactoring. The protected
`update.bat` and `update/FILES_TO_UPDATE.txt` files were not modified.

## Runtime decision

The replacement runtime must work on static hosting, run outside the UI thread, support asynchronous
input, and be terminable. The implementation will use a dedicated worker and a maintained browser
Python interpreter rather than translating Python into JavaScript. Pyodide provides the strongest
CPython compatibility but has a substantially larger cold download and asynchronous `input()` is
difficult on GitHub Pages without cross-origin-isolated shared memory. Skulpt is smaller, supports a
suspending input function, and is static-host compatible, but implements a documented subset of
Python and the standard library. The first implementation therefore uses Skulpt in a terminable
worker, pins its version, reports its limitations honestly, and keeps the worker protocol/runtime
adapter replaceable so Pyodide can be adopted later without changing the editor or project format.

## Owner decisions still required

1. Whether future Python imports should remain lossless raw-source blocks or receive a full AST-to-block
   converter. This audit implements the honest/lossless raw-source path first.
2. Whether PyBlocks’ custom license permits outside contributions and what contribution-license terms
   should apply. The project license itself will not be changed without explicit approval.
3. Whether the pinned runtime should be vendored for offline use (larger repository) or loaded from a
   trusted CDN (smaller repository, first-run network requirement).
